## 👋 About

I build **systems of AI agents that check each other's work** — orchestrators that route tasks, coder agents that generate real code, and critic agents that sandbox and review it before anything executes.

That interest runs in both directions: **up** into agent orchestration, retrieval and evaluation, and **down** into the numerical and systems layers those agents ultimately sit on — sparse linear algebra, branch-and-bound search, and CUDA.

- 🧠 Agentic RAG, LLM-as-judge evaluation, and automated fine-tuning pipelines
- ⚙️ High-performance C++/CUDA numerical computing
- 🌍 3D geospatial digital twins and developer tooling
- 💬 Ask me about multi-agent architecture, LangGraph, QLoRA, or simplex methods
